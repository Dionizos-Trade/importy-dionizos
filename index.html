🔥 Sync — Firebase
Synchronizacja online przez Firebase Realtime Database
Jak skonfigurować Firebase (raz):
1. Wejdź do Firebase Console → utwórz projekt
2. Dodaj aplikację Web i skopiuj konfigurację Firebase
3. Włącz Realtime Database w trybie testowym na start
4. Wklej poniżej dane: apiKey, authDomain, databaseURL, projectId, appId
5. Ustaw tę samą nazwę przestrzeni roboczej na każdym komputerze
apiKey

databaseURL

appId
